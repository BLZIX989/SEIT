# source_material/

Reference manuscripts (PDF/DOCX) predating this compiler — prior
project theory documents, textbooks, and papers. These are cited by
filename as historical sources in `compiler/historical/register.py`'s
`AUDITED_SOURCES` list and in several `scripts/generate_*.py` corpus
manifests, but are never opened/parsed by any code at runtime (those
citations are plain strings, not file reads) — so moving them here
does not affect the compiler or any script's behavior.
